We need to make sure that the behaviour is not caused by trivial things, such as the centering of the halo, or noise.

To make sure is is not caused by the centering, a modification of the analysis code (pNbody) has been made to center each snapshot using the shrinking sphere method. We see the same behaviour. Additionnally, pNbody provides us with a module that lets us plot histograms to determine the center (show the plots), we can see that centering is no problem. nb.histocenter(), creates 3 different histograms in 3 directions, center is at peak.
